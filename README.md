# Dragon Flock Strength Calculator

Решение кейс-задачи по расчету максимальной силы драконьей стаи по суммарному числу голов.

## Условие задачи
Известно, что у дракона может быть несколько голов (максимум 7 у одного дракона). Сила стаи равна произведению числа голов каждого из драконов.
Дано натуральное число $N$ ($0 < N < 100$) — суммарное количество голов. Требуется найти максимально возможную силу.

## Алгоритм решения
Задача решена методом **динамического программирования** (DP).
Для каждого числа голов $i$ от $1$ до $N$ мы ищем оптимальное разбиение:
`dp[i] = max(dp[i - j] * j)` для всех $1 \le j \le 7$.

Такой подход гарантирует соблюдение условия, что ни один дракон не может иметь больше 7 голов, и работает за оптимальное время $O(N)$.
