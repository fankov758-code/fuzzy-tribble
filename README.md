Шаг 1: Математический анализ задачи
Нам необходимо разбить целое число N (общее число голов) на слагаемые $a_1 + a_2 + ... + a_k = N$ так, чтобы их произведение $P = a_1 \times a_2 \times ... \times a_k$ было максимальным. При этом действует ограничение: максимальное число голов у одного дракона — 7 (т.е. $1 \le a_i \le 7$).

Логика оптимизации слагаемых:
Слагаемое 1 невыгодно, так как оно не увеличивает произведение при умножении.
Слагаемые больше 4 невыгодны, так как их можно разбить на меньшие слагаемые с бóльшим произведением (например, $5 < 2 \times 3 = 6$; $6 < 3 \times 3 = 9$; $7 < 3 \times 4 = 12$). Таким образом, ограничение "максимум 7 голов" не ухудшает оптимальный результат, так как оптимальные слагаемые всегда меньше или равны 4.
Слагаемое 4 равноценно двум двойкам ($4 = 2 \times 2$).
Среди чисел 2 и 3 выгоднее использовать тройки, так как при сумме 6: $3 \times 3 = 9$, а $2 \times 2 \times 2 = 8$.
Вывод: Лучшая стратегия — максимально использовать тройки. Если остаток равен 1, мы заменяем одну тройку и единицу на четверку ($3 + 1 = 4 \rightarrow 2 \times 2$ или просто $4$). Если остаток равен 2, мы оставляем одну двойку.
Шаг 2: Выбор архитектуры программы
Для надежности и демонстрации академического подхода мы применим динамическое программирование (DP). Это позволит гибко учитывать жесткое ограничение на максимум 7 голов у одного дракона, если в будущем условия задачи изменятся.

Формула перехода состояния:

dp[i] = max(dp[i - j] * j) для всех 1 ≤ j ≤ min(i, 7)
Шаг 3: Написание кода и юнит-тестов
Код написан на языке Python. Он содержит саму функцию вычисления силы, консольный интерфейс ввода-вывода и файл с автоматическими тестами (Unit tests) для проверки краевых значений.

# Dragon Flock Strength Calculator

Решение кейс-задачи по расчету максимальной силы драконьей стаи по суммарному числу голов.

## Условие задачи
Известно, что у дракона может быть несколько голов (максимум 7 у одного дракона). Сила стаи равна произведению числа голов каждого из драконов.
Дано натуральное число $N$ ($0 < N < 100$) — суммарное количество голов. Требуется найти максимально возможную силу.

## Алгоритм решения
Задача решена методом **динамического программирования** (DP).
Для каждого числа голов $i$ от $1$ до $N$ мы ищем оптимальное разбиение:
`dp[i] = max(dp[i - j] * j)` для всех $1 \le j \le 7$.

Такой подход гарантирует соблюдение условия, что ни один дракон не может иметь больше 7 голов, и работает за оптимальное время $O(N)$.
